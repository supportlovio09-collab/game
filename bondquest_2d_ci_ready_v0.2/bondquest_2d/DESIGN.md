# Product direction

- Name: BondQuest 2D
- Format: portrait, pass-and-play, offline-first
- Audience: couples and families
- Visual language: soft illustrated map, purple identity, large touch targets
- Session: 8–15 minutes
- Core loop: explore → enter zone → mini-game → earn hearts → unlock finale
- Size rule: engine/UI in code; compressed optional art/audio in on-demand module
- Privacy rule: no prompt answers or personal memories leave the device
